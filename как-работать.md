# Как работать по FG в Cursor

Проект FG — это Flario Game: приложение, админка, модерация. Ядро лежит в `flario-community`. Твой стол — этот репозиторий.

## Один раз: открыть два репозитория

1. В Cursor: **File → Open Folder** (или Add Folder to Workspace).
2. Добавь оба:
   - `flario-community` — регламент, ToV, UX, скилы команды;
   - `maya-moderator` — твои черновики и агенты.
3. Сохрани workspace, например `FG.code-workspace`, у себя на диске. В git его класть не обязательно.
4. Чат веди **с обоими папками в контексте**. Тогда агент видит регламент и пишет файлы только сюда.

GitHub: ты читаешь `flario-community`. Свои файлы коммить в `maya-moderator`. В `main` ядра не пушь. Ане готовое — фраза в чате «отправь на ревью».

## Каждый день

1. Открой workspace, не один пустой чат.
2. Скажи агенту задачу одним слоем: «верификация», «видео», «ситуативка», «рассылка», «заказы», «ивент».
3. Опора — `ядро/геймификация/Регламент_модератора_FG.md`. Логин админки в чат не клади.
4. Черновик текста, чеклист, список — сохраняй в папки этого репозитория (см. ниже).

## Что куда класть

| Папка | Зачем |
|---|---|
| `шаблоны/` | Тексты «Исправление», отказ, рассылка, пуш |
| `смена/` | Заметки дня: сколько заявок, что зависло |
| `claude-import/` | Выгрузка из личного Claude |
| `агенты/` | Промпты облачных агентов — копируй при создании |

## Перенос из личного Claude

Claude Project / чаты сами в Cursor не переезжают. Нужна ручная выгрузка.

1. В Claude открой проект или длинный чат.
2. Скопируй полезное: регламенты, шаблоны ответов, списки, договорённости. Не копируй пароли и ФИО без нужды.
3. Положи `.md` в `claude-import/` с понятным именем: `верификация-шаблоны.md`, `заказы-логисты.md`.
4. В чате Cursor напиши: «разложи `claude-import/`, что оставить в шаблонах, что выкинуть».

Если в Claude было знание проекта (Project knowledge) — те же файлы сюда. После разбора дубли не хранить.

## Каких агентов заводить

Не десять универсальных. Четыре рабочих плюс один «стол». Промпты — в `агенты/`. Создаёшь в Cursor: **Cloud Agent** или обычный чат с правилом из `.cursor/rules/`.

Подробности — `агенты/какие-агенты.md`.
