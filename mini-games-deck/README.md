# Презентация «Новые форматы геймификации Flario Game»

Интерактивная презентация: в каждую мини-игру можно сыграть прямо на слайде.

## Как открыть

Откройте файл `flario-mini-games.html` двойным щелчком. Интернет не нужен. Листать можно стрелками на клавиатуре или кнопками внизу, слева содержание.

## Что внутри

1. Одиночные игры: колбы, слова, большая банка, пролети кольцо, собери тройку, нажми по порядку, попади в корзинку, найди на картинке, уход за волосами, секрет Фларика.
2. Игры на двоих: приглашение «Играй с подругой», колбы вдвоём, уход вдвоём, смена вдвоём.
3. Идеи на день рождения приложения и Новый год в картинках.
4. Настройки приложения: календарь смен, заметки, Фларик сети.
5. Как это живёт в приложении: порядок, совместимость игр, планировщик недели.

## Как пересобрать

Исходники в `src/`. Готовый файл собирается командой:

```bash
node tools/build.mjs
```

Зависимостей нет. Как добавить новую игру, описано в навыке `.cursor/skills/методолог/novye-formaty-gejmifikacii/SKILL.md`.
