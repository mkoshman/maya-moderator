# Какие агенты создать

Агент здесь — отдельный чат или Cloud Agent с одной работой. Не путать с BDK-ботом в Slack: он не нужен, пока ты не ведёшь смену из Slack.

Создавай агента, когда задача повторяется. Разовую просьбу («поправь этот текст») держи в обычном чате стола.

## 0. Стол — уже есть

Этот репозиторий + правило `.cursor/rules/moderator.mdc`.  
Фраза для старта чата:

> Ты стол модератора FG. Ядро читай в flario-community, файлы пиши только в maya-moderator. Пароли не проси.

Дальше не плоди «универсального помощника».

## 1. Верификация и видео — ежедневно

**Имя:** `FG верификация`  
**Когда:** очередь «Новые», повторная регистрация, проверка видео.  
**Делает:** сверяет чеклист из регламента, предлагает текст «Исправление» / «Отказ» голосом ToV, не одобряет за тебя.  
**Не делает:** гайды продукта, бюджет, сценарии экранов.

Промпт: `агенты/верификация.md`.

## 2. Задания и рассылки — по контент-плану

**Имя:** `FG задания`  
**Когда:** квиз недели (после гайда Марины), ситуативка на сутки, текст рассылки.  
**Делает:** собирает поля админки, проверяет срок, голос, что квиз не выдуман.  
**Не делает:** менять постоянные бонусные задания.

Промпт: `агенты/задания.md`.

## 3. Заказы и призы — логистика

**Имя:** `FG заказы`  
**Когда:** трек, статус «Отправлен», сертификаты 1–10 числа, ручной заказ-исключение.  
**Делает:** чеклист статусов, формулировки пуша, список что передать логистам.  
**Не делает:** считать KPI без выгрузки.

Промпт: `агенты/заказы.md`.

## 4. Ивенты

**Имя:** `FG ивент`  
**Когда:** создать ивент, лимит, резерв, рассылка участницам.  
**Делает:** поля из регламента §8, текст приглашения, что нажать в админке.  
**Не делает:** решать бюджет ивента.

Промпт: `агенты/ивент.md`.

## Что не создавать сейчас

- Агента «стратег / KPI» — это стол Анны и выгрузки.
- Агента «методолог гайда» — гайд и квиз собирает Марина.
- Агента «бокс месяца» — другая зона, и без месяца чат остановится.
- Отдельного агента на каждую вкладку админки — потонет в чатах.

Когда из Claude переедут ещё слои (амбассадоры, закрытый чат) — добавим пятого, не раньше.
